# citiusmodels

Fitted model artefacts for [`citius`](../citius), served via GitHub Releases
with local caching — the same pattern as `torpmodels`, `pannamodels` and
`bouncermodels`.

## What lands here

- Aging curves per event family (GAM fits)
- Event-level variance priors estimated from pooled histories
- Any Stan posteriors for flagship events

Models are kept out of the main package so `citius` stays lightweight and
installable without large binary artefacts.
